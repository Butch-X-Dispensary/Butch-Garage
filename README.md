🛠️ Butch Garage
Isang modernong website design para sa Butch Garage. Nakatuon ito sa serbisyo ng mga sasakyan, maintenance, at showcase ng mga custom builds. Ang disenyo ay matapang, malinis, at user-friendly.

🌟 Mga Tampok (Features)
Service Booking: Madaling interface para sa pag-iskedyul ng repair.

Vehicle Showcase: Gallery ng mga sasakyang natapos sa garage.

Mobile Ready: Responsive design na swak sa kahit anong device.

JS Powered: Mabilis na interactivity gamit ang JavaScript.

🛠️ Tech Stack
HTML5 / CSS3 (Custom Styling)

JavaScript (ES6) - Para sa booking logic at UI effects.

🚀 Paano Gamitin
I-clone ang project:

Bash
git clone https://github.com/username/butch-garage.git
Buksan ang index.html sa iyong browser.

const services = ["Tune-up", "Oil Change", "Brake Check", "Custom Build"];

  console.log(`Service Available: ${service}`);
